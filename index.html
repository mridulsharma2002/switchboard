    The catch

    How it's measured: 60 prompts in 6 categories (bench/prompts.json). Switchboard's free rules route every step. Token counts come from a cost model, not real responses. The baseline is one Opus 5.5 call writing the same amount of output. Switchboard's side includes the triage, planning and check calls. Thinking tokens aren't counted on either side. Reproduce it with npm run bench.

    03 · How it works

    An operator for your prompts.Five moves, every run.

    1. TriageFree rules score the task from 1 to 5. Haiku breaks ties.
    2. PlanBig tasks split into 2 to 5 steps, each with its own difficulty.
    3. PatchEach step goes to the cheapest model for its difficulty.
    4. CheckHaiku grades the step. A fail moves it up one model and retries.
    5. ComposeFinished steps are stitched into one answer. No extra call.
    route.py
    for step in plan(task):
    model = cheapest_model_for(step.difficulty)
    loop:
        out = run(model, step)        # busy or refused → next model
        if check(out).passes: break
        if over_budget or at_top: break
        model = one_level_up(model)   # escalate and retry
    # two clean passes in a row: drop back down
