Switchboard

Side project · by Mridul Sharma

Most AI tasks mix hard parts and easy parts. Switchboard splits a task into steps and sends each one to the cheapest Claude model that can do it well. A small model checks every step. If a check fails, the step moves up a model and tries again.

Scripted replies. Step 2 fails its check on Sonnet and moves up to Opus. The README drops down to Haiku.

Run npm run bench to reproduce it.

    How it works

    1. Triage. Free rules score the task from 1 to 5. If they aren't sure, Haiku decides.
    2. Plan. A bigger task is split into 2 to 5 steps, each with its own difficulty.
    3. Route. Each step goes to the cheapest model for its difficulty.
    4. Check. Haiku grades the step. A fail moves it up one model, and it tries again with the reviewer's note.
    5. Compose. The finished steps are joined into one answer, with no extra call.
    for step in plan(task):
    model = cheapest_model_for(step.difficulty)
    loop:
        out = run(model, step)        # busy or refused → next model
        if check(out).passes: break
        if over_budget or at_top: break
        model = one_level_up(model)   # escalate and retry
    # two clean passes in a row: drop back down
